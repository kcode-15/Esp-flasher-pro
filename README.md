# The best way to flash your esp with micropython and demo projects

Esp flasher pro is a usefull tool used to flash demo projects and your own files onto your esp with micropython






# setup
to setup run

``` gh repo clone kcode-15/Esp-flasher-pro ```

and then to run the script in the directory run
``` python3 main.py ```
